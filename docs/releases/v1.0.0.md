# Heureka v1.0.0

First release of **Heureka**, an inspectable inventive problem-solving app that turns a raw technical problem into ranked solution candidates using TRIZ and SCAMPER.

Heureka combines an Angular frontend, a NestJS gateway, and a Python Google ADK agent. The agent uses LLMs where judgement is useful, deterministic code where correctness matters, and returns a five-step reasoning trail instead of only a final answer.

## Highlights

- Added the full Heureka product flow: problem normalization, contradiction extraction, deterministic TRIZ lookup, TRIZ and SCAMPER candidate generation, candidate scoring, deterministic winner selection, and final trail assembly.
- Added the Python Google ADK agent with a `SequentialAgent` pipeline, parallel TRIZ/SCAMPER candidate generation, deterministic `choice_selector`, and deterministic `trail_assembler`.
- Added the complete TRIZ contradiction matrix lookup in `apps/agent/app/triz.py`.
- Added the Angular analysis interface with a Polish "engineering sheet" UI, analysis form, evaluation-mode support, ranked candidates, winner/runner-up presentation, and reasoning trail rendering.
- Added an interactive pipeline diagram that follows the analysis phases and highlights active agent nodes while processing.
- Added voice input: browser-side recording in the frontend and server-side Google Cloud Speech-to-Text transcription through the NestJS API.
- Added accessibility controls for dark mode, high contrast, and text enlargement, with preferences persisted across sessions.
- Added methodology and team pages, plus product/design documentation for the Heureka concept, UX, frontend architecture, backend/LLM architecture, and design system.

## Architecture

- `apps/frontend`: Angular 21 standalone application using signals, SCSS design tokens, and `ng-diagram`.
- `apps/api`: NestJS 11 gateway exposing `/solve`, `/speech/transcribe`, and Swagger docs at `/api/docs`.
- `apps/agent`: Python Google ADK agent served through FastAPI, with A2A support, Gemini/Vertex AI integration, and Cloud Run deployment metadata.
- Tooling: Nx monorepo, pnpm workspace configuration, ESLint, Dockerfiles, GitHub Actions, and Nx Cloud integration.

## Deployment And Operations

- Added Docker-based deployment paths for the frontend and API.
- Added Cloud Run deployment workflows for API and frontend using GitHub Actions and Workload Identity Federation.
- Added `tools/deploy-api.sh` to build and deploy the API with live agent service integration.
- Added Terraform infrastructure for the agent Cloud Run service, telemetry, IAM, storage, and shared logging assets.

## Quality And CI

- Added Nx Cloud support and self-healing CI hook.
