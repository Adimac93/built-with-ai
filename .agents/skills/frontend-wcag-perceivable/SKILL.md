## WCAG Perceivable Guidelines

- Provide text alternatives for non-text content (images, icons, graphics) with appropriate `alt`
- Ensure pre-recorded audio-visual content has captions, audio descriptions, and transcripts
- Maintain minimum contrast ratios: 4.5:1 for normal text, 3:1 for large text and UI components
- Enable content to be presented without losing information when zoomed or resized
- Avoid using color alone to convey information — pair with text, patterns, or icons
- Provide controls to pause, stop, or hide moving, blinking, or auto-updating content
- Ensure text can be resized up to 200% without loss of content or functionality
- Use responsive design that adapts to different viewports without horizontal scrolling
- Allow users to customize text spacing without breaking layouts
