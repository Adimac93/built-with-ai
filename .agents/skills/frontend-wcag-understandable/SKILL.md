## WCAG Understandable Guidelines

- Specify page language and any language changes using `lang` attributes
- Ensure components with the same functionality behave consistently across the application
- Provide clear labels, instructions, and error messages for user inputs
- Implement error prevention for submissions with legal or financial consequences (confirmation, review, undo)
- Make navigation consistent with predictable patterns for menus and interactive elements
- Ensure receiving focus or changing settings does not automatically trigger unexpected context changes
- Design context-sensitive help for complex interactions
- Use clear language; define unusual terms, abbreviations, and jargon
- Provide visual and programmatic indication of current location within navigation
